# Checklist of WO-N

Copy this file to `.forja/WO-N/checklist.md` and replace `WO-N`. Every step ends
as `[x]` (done) or `[SKIP] <reason in one line>`. Do not deliver with steps left
as `[ ]`. Each `[SKIP]` goes to the delivery report as an informative item.

## start
- [ ] S1 Read the Work Order and its contract
- [ ] S2 Create `.forja/WO-N/` and this checklist
- [ ] S3 Read the Project skills and check the contract against the code
- [ ] S4 Take the Work Order and create the branch
- [ ] S5 Tell the developer about overlaps with other Work Orders
- [ ] S6 Isolated environment

## execute
- [ ] E1 Follow the Plan in order
- [ ] E2 Keep this checklist up to date
- [ ] E3 Stop and escalate on a stop condition
- [ ] E4 Note adjustments against the contract

## verify
- [ ] V1 Verify by rounds
- [ ] V2 Commits and pushes depend on the verification
- [ ] V3 Run the tests of the contract
- [ ] V4 Test visible changes in a real browser
- [ ] V5 Review your own work by dimensions
- [ ] V6 Say which test data could not be guessed

## integrate
- [ ] I1 Bring the branch up to date and verify again
- [ ] I2 Keep both sides of shared registries
- [ ] I3 Renumber your own numbering conflicts
- [ ] I4 Stop on conflicts outside the scope
- [ ] I5 Check the pull request is still open before pushing
- [ ] I6 Open and link the pull request

## report
- [ ] R1 Report tests, delivery, findings and pull request to Forja
- [ ] R2 Update the living documentation
- [ ] R3 Do not complete the Work Order
- [ ] R4 Clean up what you created
- [ ] R5 On permission or claim errors, do not retry in a loop
